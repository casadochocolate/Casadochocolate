# Casa Do Chocolate

## Publicar en GitHub Pages

La versión estática para GitHub Pages está en `docs/`. En GitHub abre **Settings > Pages**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/docs`, y guarda.

La aplicación Django completa continúa disponible para Render: incluye base de datos, panel de administración y migraciones.
